# Catalogo LRP

## Porto ao Vivo (`horarios/`)

App web com as próximas partidas, em tempo real, do **Metro do Porto** e da **STCP**.

- Pesquisa de paragens/estações por nome e botão 📍 para paragens perto de ti
- Partidas com indicação de *tempo real* vs *horário*, atrasos e cancelamentos
- Atualização automática a cada 30 s; favoritos guardados no dispositivo
- Dados: plataforma aberta Porto Digital (OpenTripPlanner GraphQL), configurável em ⚙️

Abre `horarios/index.html` no browser (ou via GitHub Pages em `/horarios/`). No telemóvel,
"Adicionar ao ecrã principal" para a usar como app.
